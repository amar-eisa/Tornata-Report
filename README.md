# Tornata Report

خمسة تقارير مشفرة باستخدام AES-256-GCM ومفتاح مشتق من اسم المستخدم وكلمة المرور بواسطة PBKDF2-SHA256 (600,000 دورة). لا توجد كلمة مرور أو بيانات تقارير صريحة في ملفات الموقع. الخط محلي. فك التشفير داخل المتصفح، والمفتاح يبقى في sessionStorage حتى تسجيل الخروج أو إغلاق التبويب.

النشر من main / (root) على GitHub Pages. هذه حماية بالتشفير وليست خدمة حسابات أو صلاحيات على خادم.
